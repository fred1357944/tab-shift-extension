Tab Shift Privacy Policy

Effective date: 16 September 2026

Tab Shift is a Chrome extension that rearranges the active tab and moves it between windows using keyboard shortcuts. It is developed by Hung Yi Lai (fred1357944@gmail.com).

What we collect

Nothing. Tab Shift does not collect, store, sell, or transmit personal data. There is no account, no analytics, and no remote server.

What runs on your computer

When you press a shortcut, the extension asks Chrome for the active tab’s id, index, pinned state, and window id, then calls Chrome APIs to move that tab. It does not read page URLs, titles, cookies, or page content. Tab identifiers exist only in memory for that command and are not written to disk.

Network connections

Tab Shift makes no network requests. It does not load remote code, fonts, or scripts.

Permissions

The published package requests no host permissions and no optional permissions. It uses only the Chrome commands, tabs-move, and windows APIs needed to rearrange tabs. It does not request the tabs permission, so it cannot read browsing history.

What we do not do

  • No browsing-history logging
  • No advertising or tracking
  • No sale or transfer of user data
  • No use of data to determine creditworthiness

Deletion

There is no stored user data to delete. Uninstalling the extension from chrome://extensions removes it completely.

Changes

If a future version starts collecting or transmitting data, this policy will be updated first, the Chrome Web Store listing will be updated, and any new collection will require an opt-in.
